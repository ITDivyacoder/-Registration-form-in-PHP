# 📝 PHP Registration Form

A clean, modern, and user-friendly **Registration Form** built using **HTML, CSS, PHP, Bootstrap, and MySQL**.  
This project demonstrates how to create a registration form, validate user input, securely hash passwords, and connect PHP with a MySQL database.

- 🚀 Register Button

---

## 📌 About The Project

This project is a basic **PHP Registration System** created to understand the fundamentals of backend web development.

When a user submits the registration form:

1. The form collects the user's information.
2. PHP receives the submitted data.
3. The input is validated.
4. The password is securely hashed using PHP's `password_hash()` function.
5. The data is connected to the MySQL database.
6. The registration information can then be stored in the database.

This project is useful for learning **PHP form handling, validation, password hashing, and MySQL connectivity**.
